# Dogtective

a detective game app built using spritekit by 5 indie developers that love to explore and live the moments


## Project Structure


```
Dogtective/
    Screens/          ← full SwiftUI screens
    Components/       ← reusable SwiftUI views
    Scenes/           ← SpriteKit scenes
    Entities/         ← custom SKSpriteNode subclasses
    Model/            ← data/storage
    ViewModel/        ← business logic of the screen and bridge to gamescene
    Systems/          ← business logic from the gamescene, using extension
```


## Build with

- SwiftUI
- SpriteKit
- AVFoundation
- SwiftData
- Modified-ECS structure
- Lottie
